This appendix presents the administrator acceptance survey instrument used to support the usability and alerting discussion in Chapter~\ref{ch:result_discuss}.

The administrator acceptance instrument asked respondents to rate their level of agreement with each statement using a five-point scale: 1 for strongly disagree, 2 for disagree, 3 for neutral, 4 for agree, and 5 for strongly agree. The survey focused on dashboard usability, fuel monitoring, anomaly alerts, driver-safety support, maintenance monitoring, and overall system satisfaction.

\section{Dashboard and Real-Time Monitoring}

\begin{enumerate}
    \item The dashboard provides a clear and easy-to-understand overview of fleet-vehicle status, including fuel, speed, location, and alerts.
    \item The dashboard updates are timely enough to support real-time fleet monitoring.
    \item The route-tracking/map feature is useful for monitoring fleet-vehicle movement.
    \item The trip-history feature helps review past fleet-vehicle operations.
    \item The fuel level display is easy to interpret.
    \item The telemetry-log view provides enough details for checking fleet-vehicle activity.
    \item The dashboard layout is organized and easy to navigate.
\end{enumerate}

\section{Fuel Monitoring Accuracy}

\begin{enumerate}
    \item The system provides useful information about fuel level changes during operation.
    \item The fuel monitoring feature can help identify possible abnormal fuel usage.
    \item The fuel data shown on the dashboard is helpful for reviewing fleet-vehicle fuel behavior.
\end{enumerate}

\section{Anomaly Detection and Alerts}

\begin{enumerate}
    \item The anomaly alerts are useful for identifying possible fuel theft, leakage, or unusual fuel consumption.
    \item The alert information is clear and understandable.
    \item The dashboard makes it easy to review and resolve alerts.
    \item The alert system can help fleet administrators respond faster to fuel-related issues.
    \item The alert status and alert history are useful for record keeping.
\end{enumerate}

\section{Driver Safety and Rest Alerts}

\begin{enumerate}
    \item The driver-rest alert feature is useful for reminding drivers to take breaks.
    \item The system supports safer driving by monitoring long driving periods or distance travelled.
    \item The HMI alert interface is understandable for drivers.
    \item The rest-alert records are useful for reviewing driver activity.
\end{enumerate}

\section{Maintenance Monitoring}

\begin{enumerate}
    \item The maintenance-monitoring feature is useful for tracking fleet-vehicle service needs.
    \item The mileage-based maintenance reminder can help improve preventive maintenance.
    \item The maintenance information shown on the dashboard is easy to understand.
    \item The system can help reduce the chance of missed maintenance checks.
\end{enumerate}

\section{Overall System Usability and Satisfaction}

\begin{enumerate}
    \item The system is useful for fleet monitoring.
    \item The system can help improve fuel accountability.
    \item The system can help improve operational visibility for the company.
    \item I would recommend further development or deployment of this system.
    \item Overall, I am satisfied with the system.
\end{enumerate}

\section{Open-Ended Feedback Questions}

\begin{enumerate}
    \item Which feature of the system is the most useful?
    \item Which part of the system needs improvement?
    \item Were there any confusing parts of the dashboard or HMI?
    \item What additional features would you recommend?
\end{enumerate}
